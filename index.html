Основы HTML

HTML используется для создания структуры веб-страниц. С помощью HTML-тегов можно размещать текст, изображения, списки, формы и другие элементы.

В данной лабораторной работе используются основные HTML-теги и атрибуты, изученные на занятии.

Основные элементы HTML

  • Заголовки
  • Параграфы
  • Списки
  • Изображения
  • Формы

Этапы создания HTML-страницы

  1. Создать файл с расширением .html
  2. Добавить базовую структуру документа
  3. Добавить необходимые HTML-теги
  4. Сохранить файл
  5. Открыть готовую страницу в браузере
